About This Page

Not every tool is worth a dedicated write-up — some things get built in an afternoon to fix one specific annoyance, get used a few dozen times, and never need to be more than that. This page is a home for those: small scripts, one-off automations, and utilities that solved a real problem without needing to become a "project" in the fuller sense of the other pages here.

The Utilities

Python

File & naming cleanup scripts

Small scripts for batch-renaming and reorganizing CAD exports, drawing sheets, and photo dumps into consistent naming conventions — the kind of tedious task that's trivial to script and easy to keep putting off otherwise.

JavaScript

Quick-and-dirty browser helpers

Bookmarklets and userscripts written to fix one specific annoyance on a site I use often — a missing keyboard shortcut, a layout that doesn't work well on a given screen size, a form that needs pre-filling.

Python

Data-wrangling one-offs

Scripts written to reshape or clean up a specific dataset — sensor logs, competition results, exported spreadsheets — for a single analysis, without the overhead of building a reusable tool around a problem that only came up once.

Note: this page is intentionally a living list — new entries get added here as more small tools come up, rather than each one getting its own page.
