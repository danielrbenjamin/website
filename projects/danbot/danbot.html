DanBot: 3D Printing Command Center

A Slack bot with Model Context Protocol (MCP) server integration for 3D printer monitoring and homelab server status tracking — so checking on a print doesn't mean walking downstairs.

Problem

Running a 3D printer and a small home server means a constant stream of small questions — is the print still going, did it fail overnight, is the server actually up. None of those questions are worth opening a dashboard for individually, but they're also exactly the kind of thing you want answered without leaving whatever chat window you're already in.

DanBot exists to answer those questions inside Slack, where I already spend the day, instead of a purpose-built dashboard I'd have to remember to check.

Architecture

DanBot is a Python Slack bot paired with a Model Context Protocol (MCP) server, which exposes printer and server state as tools an LLM-driven chat interface can call directly. That MCP layer is the piece that makes the bot more than a fixed set of slash commands — instead of hardcoding every question I might want to ask, the MCP server exposes the underlying capabilities, and the model composes them into an answer.

Printer Monitoring

The printer runs Klipper firmware, which exposes a structured API for job progress, nozzle and bed temperatures, and error states. DanBot polls that API and surfaces it through Slack — a running print's status, an alert if something's gone wrong, or a quick temperature check, all without needing to be in the same room as the printer.

Server & Deployment

The bot itself runs in Docker on a home server, alongside status checks for the other services running there — the kind of small homelab networking work that's invisible when it's working and very visible the moment it isn't. DanBot reports on that infrastructure too, so the same chat window that tells me a print finished also tells me if the machine hosting it is under load.

Results

DanBot turned "walk over and look at the printer" into "ask Slack," and turned "did the server survive last night" into the same thing. It's a small tool, but it's the kind that gets used every single day rather than the kind that gets built once and forgotten.
