Suspension Load Analysis Pipeline // python

Turning raw vehicle parameters into the load cases that drive every structural decision.

PythonNumPyPacejka MF5.2ANSYS
UBC Formula Electric · 2026 · analysis

This pipeline replaced a tangle of legacy MATLAB scripts with a single, reproducible Python workflow. It takes vehicle parameters — mass distribution, CG height, track, wheelbase, tire data — and produces the full set of design load cases the chassis and suspension teams need for FEA.

At its core is a Pacejka MF5.2 tire model that generates realistic lateral and longitudinal force curves. From these, the pipeline assembles eight distinct design load cases (braking, cornering, combined, bump, and their combinations) and exports each as a clean CSV keyed to the ANSYS chassis FEA setup.

The result: what used to be a manual, error-prone afternoon is now a parameter change and a re-run. Every downstream structural decision traces back to a documented, versioned load case.
